# Riddhi Siddhi Dental Hospital

Official website for **Riddhi Siddhi Dental Hospital**, Jaipur. A modern web application providing comprehensive dental care information, appointment booking details, and service offerings.

## Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/workinghub40344/riddhi-siddhi-elevate.git
   ```

2. Navigate to the project directory:
   ```sh
   cd riddhi-siddhi-elevate
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Run the local development server:
   ```sh
   npm run dev
   ```

5. Build for production:
   ```sh
   npm run build
   ```
